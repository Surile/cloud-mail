# 申请制页面实施计划（feat/application-page 分支）

**目标**：LinuxDo 登录后提交开号申请 → trust_level ≥ 阈值(默认3，后台可调，0=关闭)自动通过并建号绑定；低于阈值进人工审核 → 通过即建号+绑定 oauth → 申请人重新登录进站。注册开关关闭不影响本功能。

## 一、后端（mail-worker）
1. 实体 `src/entity/apply.js`：表 apply（oauth_user_id/platform/username/name/avatar/trust_level快照/email期望地址/reason/status 0待审1通过2驳回/remark/admin_id/create_time/update_time）
2. 迁移 v3_4DB：建表+索引 idx_apply_oauth/idx_apply_status + 权限行 ID 37/38/39（申请管理/apply:query/apply:audit）+ setting 加列 apply_auto_trust_level INTEGER DEFAULT 3
3. `apply-service.js`：submit（验 apply-JWT→读 oauth 行最新 trust_level 快照→邮箱校验+理由≥10字+防重复→插单→快照≥阈值则立即内部 approve(adminId=0)：复用 userService.add 建号+oauth 绑定，TG 标注自动通过；失败兜底留待审）、mine、list（分页/筛选）、approve、reject（TG 发送小辅助）
4. 路由：/oauth/apply/add|mine（/oauth 排除段内自验 token）；/apply/list|approve|reject 进 requirePerms/premKey
5. oauth-service：saveAndLogin 未绑定时返回 applyJwt(7d)；修复 clearNoBindOathUser 不删有待审单的身份
6. 设置接口暴露 applyAutoTrustLevel；后端 zh/en 文案约 6 键

## 二、前端（mail-vue）
7. axios 拦截器：显式 Authorization 头不被空值覆盖
8. 申请页 views/apply/index.vue：登录引导/表单(前缀+后缀+必填理由)/待审30s轮询/驳回重申/通过提示重登四态；高信任提交后即时显示已通过
9. 登录页回调：暂存 applyJwt，oauthNext=apply 时跳申请页，不动现有绑定弹窗
10. 路由 /apply 注册+守卫豁免
11. 审核页 views/apply-admin/index.vue：表格(头像/平台/信任等级/地址/理由/状态)+通过/驳回+筛选分页；perm.js 挂 /apply-audit(v-perm apply:query)+侧栏菜单
12. 系统设置页加“自动通过阈值”数字输入(0=关闭)；zh/en 文案约14键
